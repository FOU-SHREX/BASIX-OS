## BASIX OS

A simple WebOS made by CAPYBARA!

## About

BASIX OS is a Basic browser based OS with capybara theme.

This is my first time working on a project with HTML, CSS and JAVAScript.

## Features

- Welcome screen
- Live clock
- Draggable windows
- Open and close windows
- Capy Notes - Write and copy text
- Capy Info - About Capybara and BASIX OS
- Simple brown and cream theme

## Try BASIX OS

You can try BSASIX OS here:

[Launch BASIX OS](https://fou-shrex.github.io/BASIX-OS/)

Click on Start BASIX to enter the desktop.

## How to Run

1. Download the repository as ZIP.
2. Extract the files.
3. Open `index.html` in your browser.
4. Click Start BASIX.
